# Qué Torta - Proyecto final de E-commerce

Sitio web de demostración para una pastelería llamada **Qué Torta**. Permite visualizar el catálogo propio, agregar tortas al carrito, modificar cantidades, eliminar productos y simular una compra. También incluye una sección de productos de otros comercios, cargados desde una API .

## Tecnologías
HTML5, CSS3, Bootstrap 5, JavaScript, Fetch API, LocalStorage y Formspree.

## Carrito
El carrito permite agregar tortas del catálogo propio, modificar cantidades, eliminar productos y calcular el total. 

## Formulario
El formulario está conectado a Formspree
